# v0.2.0 PR Plan

This document outlines the planned pull requests (PRs) for v0.2.0, ordered according to the architectural roadmap in ADR-020.

All PRs must follow the safety boundaries and invariants defined in the ADR series.

## PR Sequence

### PR1: Confidence Signal (Complete)
- **ADRs:** 021–025
- **Description:** Deterministic, non-authoritative confidence signal processor with EWMA, failure window, and strict invariants.
- **Status:** Complete (code, tests, ADR-021–025 committed)

### PR2: Policy Gate Contract (Complete)
- **ADRs:** 038
- **Description:** Exclusive consumer of confidence and sole control boundary mapping epistemic signals deterministically to execution modes (EXECUTE, RETRY, DEGRADE, HALT). Pre-execution authorization boundary enforcing purity, determinism, side-effect freedom, monotonicity, and explicit default semantics.
- **Must Never Happen:**
  - Confidence influencing control without passing through the policy gate
  - Execution occurring without policy gate authorization
  - Implicit or runtime gate selection
  - Non-deterministic or stateful behavior inside the policy gate
  - External calls (including LLMs, network, or I/O) inside the policy gate
- **Tests:** Determinism, monotonicity, confidence validation, rule precedence, failure window handling, proposed_action uninterpreted, rule_id/reason always present
- **Status:** Complete (code, tests, ADR-038 committed)

### PR3: Agent Loop & Policy Gate Integration (Complete)
- **ADRs:** 039
- **Description:** Enforces the policy gate as the sole pre-execution authorization boundary in the agent loop. Invokes the policy gate exactly once per proposed action in a single deterministic pre-execution location and enforces gate decisions (EXECUTE, HALT, RETRY, DEGRADE). No execution path bypasses the gate.
- **Must Never Happen:**
  - Execution without prior gate authorization
  - Execution of HALT/RETRY/DEGRADE outcomes as if authorized
  - Ad hoc degraded execution paths not explicitly defined
  - Post-execution gate enforcement
  - Retry generation or retry decision-making inside the gate
  - Implicit retry orchestration not explicitly defined by the surrounding control layer
- **Tests:** Gate always invoked, HALT/RETRY/DEGRADE prevent execution, no execution without gate, determinism, exactly one policy gate evaluation per proposed action
- **Status:** COMPLETE (minimal enforcement seam in eck/agent_loop.py implemented; full invariant test suite in tests/test_agent_loop.py passing; all "Must Never Happen" items prevented)

### PR4: Memory Retrieval (In Progress)
- **ADRs:** 026–030
- **Description:** Read-only, advisory-only memory context (no control authority) with enable/disable gating and deterministic formatting.
- **Must Never Happen:**
  - Retrieval execution when disabled
  - Prompt drift when retrieval is disabled
- **Status:** IN PROGRESS (scaffold complete, tests passing; next: canonical formatting, full coverage)

### PR5: Similarity Upgrade (embeddings / cosine)
- **ADRs:** 031–032
- **Description:** Optional similarity retrieval API and embedding integration.
- **Must Never Happen:**
  - Core package becoming non-stdlib
  - Optional dependency failure breaking the agent
- **Status:** PENDING

### PR6: Prompts Integration Cleanup
- **ADRs:** 033
- **Description:** Cleanup and guardrails for prompt usage.
- **Must Never Happen:**
  - New prompt usage changing runtime behavior without tests
  - Hidden reliance on prompt strings as API
- **Status:** PENDING

### PR7: CI Workflow & Observability
- **ADRs:** 034–037
- **Description:** CI workflow, test coverage metrics, observability.
- **Must Never Happen:**
  - CI introducing network/external dependencies
  - CI requiring non-stdlib runtime dependencies for core
- **Status:** PENDING

## Safety & Invariant Checklist

All PRs must satisfy these invariants:
- No new authority surfaces through capability layers
- No silent coupling: signals must not alter behavior without explicit policy gate mediation
- No dependency creep: core remains stdlib-only
- No prompt drift when optional features are disabled
- No split-brain state: single source of truth for new variables

## Summary

v0.2.0 builds a deterministic core with explicit policy gate mediation as the control seam. Confidence (PR1), Policy Gate (PR2), and Agent Loop Integration (PR3) form the foundation; memory and similarity follow as advisory layers.
