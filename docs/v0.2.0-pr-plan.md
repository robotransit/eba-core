# v0.2.0 Implementation PR Plan

**Goal:** Convert the locked v0.2.0 design (ADR-020–ADR-037) into code without violating any invariants or red lines.

**Rules for all PRs:**
- Never break existing core behavior
- Core must remain strictly stdlib-only at all times
- All changes must preserve relevant locked invariants (including prompt equivalence, atomic fallback, and guardrails where applicable)
- Each PR must include relevant tests for the invariants it touches

---
