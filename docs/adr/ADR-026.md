# ADR-026: Retrieval Semantics & Contract

**Status**  
Locked (semantic invariant for v0.2.0 core)

## Objective

Define the exact retrieval semantics and contract for memory-aware prediction context in ECK, limited to the shape of returned items, deterministic formatting, read-only boundary, and equivalence behaviors for disabled, enabled-with-empty, and no-context states.  

This ADR is strictly scoped to A2.1 and establishes the foundational contract for memory retrieval without introducing any authority, coupling, or influence on other components.

## Decisions

1. **Shape of Returned Items**  
   Retrieval returns a structured, read-only list of `TaskRecord` items that represent historical task entries from the append-only WorldModel.

2. **Deterministic Formatting Contract**  
   The returned list is deterministically ordered according to a stable, version-locked rule.  
   Formatting serializes the list into a canonical memory section block within the prediction prompt, using deterministic delimiters to ensure structural separability from system instructions and task-specific logic.

3. **Read-Only Boundary**  
   Retrieval provides access to `TaskRecord` items solely for observational use in prediction context.  
   Returned items are immutable by construction, and the contract exposes no mutation pathways to the underlying WorldModel.

4. **Equivalence Behaviors**  
   - Disabled retrieval mode produces no context.  
   - Enabled retrieval with no matching or available items produces no context.  
   - No context (from disabled or enabled-with-empty) results in the canonical no-context prompt form, identical to a system without memory retrieval.

## Invariants

- Retrieval output is always a list of `TaskRecord` items, possibly empty.  
- List order is deterministic and stable according to a version-locked rule.  
- All `TaskRecord` items are immutable by construction with no exposed mutation pathways.  
- Disabled mode, enabled-with-empty, and no-context states produce bit-for-bit identical prompt forms (including whitespace and delimiters), with the diff between disabled and enabled+empty being exactly empty; this is a testable condition.  
- Memory **MUST** remain advisory/context only. Memory retrieval or scoring **MUST NOT** gain any behavioral authority or alter generation/prediction in a manner that confers behavioral authority (e.g., override, delegation, or non-advisory control) without explicit policy gating.  
  Memory **MAY** alter prediction text through advisory context injection, but only under explicit structural separation and without gaining authority (prediction owns generation).  
- No coupling to confidence, policy modes, breadth, or gating occurs through this contract.  
- A1 confidence semantics remain closed and unaffected.

## Must Never Happen

- Retrieval returning non-list or mutable structures.  
- Non-deterministic ordering or formatting of retrieved items.  
- Exposure of mutation pathways through the retrieval contract.  
- Divergent prompt forms (including whitespace or delimiters) between disabled, enabled-with-empty, and no-context states.  
- Silent influence on confidence, policy, breadth, or gating via retrieval.  
- Reopening or reinterpretation of A1 semantics.  
- Memory gaining behavioral authority, overriding or delegating generation, or altering prediction without explicit structural separation and policy gating.
