# ADR-028: Retrieval Influence Semantics

**Status**  
Locked (semantic invariant for v0.2.0 core)

## Objective

Define the precise semantics governing how retrieved memory context may influence prediction generation in ECK — strictly as advisory, additional evidence injected into the prompt, with no transfer of behavioral authority, no delegation of generation responsibility, and enforced structural separation to prevent blending or accidental authority creep.

This ADR is strictly scoped to A2.3 and builds directly on the retrieval contract (ADR-026) and enable/disable semantics (ADR-027), without reopening prior decisions, introducing new authority surfaces, coupling memory to confidence/policy/breadth/gating, or expanding into A2.4, A2.5, or later phases.

## Decisions

1. **Injection as Advisory Evidence Only**  
   When memory retrieval is enabled and items are available, the formatted memory context (per ADR-026 canonical memory section block) is injected into the prediction prompt solely as additional observational evidence.  
   The injection augments the input available to the LLM but confers no decision-making or control authority.

2. **Prediction Owns Generation**  
   The prediction component (`prediction.generate_prediction`) retains full ownership and responsibility for the final generated output.  
   Memory context is treated as context, not instruction or directive; the LLM is never instructed to delegate, defer, or override its own reasoning to the retrieved history.

3. **Structural Separability Requirement**  
   The memory context must be injected in a structurally separable manner using deterministic delimiters and/or clear section markers (as already required by ADR-026 formatting contract). This separation ensures:  
   - Clear visual and syntactic distinction from system instructions and task-specific prompt logic.  
   - Prevention of accidental blending or conflation during prompt interpretation.  
   - Maintainability of the advisory-only posture even under varying LLM sensitivities.

## Invariants

- Memory context injection is advisory only: it **MAY** alter the prediction text by providing additional evidence, but only through explicit structural separation and without gaining authority.  
- Prediction owns generation: the generation process never delegates, overrides, or delegates behavioral control to retrieved memory content.  
- Structural separability is an invariant: the memory section must remain isolated via deterministic delimiters and/or clear section markers, preventing blending even under varying LLM tokenization behaviors.  
- Memory **MUST NOT** influence confidence scoring, task breadth estimation, policy mode transitions, or any gating mechanism.  
- No behavioral authority is conferred to memory: no override, delegation, or non-advisory control arises from context injection (per §19 red line).  
- A1 confidence semantics, ADR-026 retrieval contract, and ADR-027 toggle invariants remain closed and unaffected.  
- Injection occurs only when retrieval is enabled and items exist; disabled or empty cases follow ADR-026/027 equivalence (no context, no drift). In practice, this means the prompt string generated when retrieval is disabled is byte-for-byte identical to the prompt string generated when retrieval is enabled but yields zero items — including all whitespace, delimiters, and section boundaries.

## Must Never Happen

- Memory context being treated as instruction, directive, or authoritative source by the prediction process.  
- Delegation of generation responsibility from prediction to retrieved memory (prediction must always own final output).  
- Blending or accidental authority transfer due to insufficient structural separation (e.g., missing delimiters, merged sections).  
- Any influence — direct or indirect — on confidence values, breadth decisions, policy modes, or execution gating from memory context.  
- Silent coupling or residual authority creep when injection occurs.  
- Divergent prompt semantics or behavior when comparing injected vs. non-injected cases beyond the advisory evidence difference.  
- Reopening or reinterpretation of ADR-026, ADR-027, A1 semantics, or §19 red lines.
